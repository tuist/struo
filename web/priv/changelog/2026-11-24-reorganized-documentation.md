---
title: Reorganized documentation, and an index for coding agents
date: 2026-11-24
---

The guides are reorganized so similar pages read the same way. Every toolchain
guide now starts with prerequisites and your existing project, then covers
declaring targets, dependencies, limitations, and target kinds. Every
infrastructure provider guide covers prerequisites, configuration,
authentication, usage, and cleanup in that order. Every SDK guide covers
installation, a quick start, blobs, action keys, and errors. Pages focus on
what you do and see, with less detail about how Struo works inside.

Coding harnesses and project memory now share a Coding Agents section, and
Language Libraries is now SDKs.

The site now serves `/llms.txt`, an index of every documentation page with a
link to its Markdown source, so coding agents can find the right page directly.
