---
title: Tuist shows each remote execution run
date: 2026-11-25
---

Every action Struo runs through Tuist remote execution now names the run it
belongs to, along with the action's kind and target. Tuist's Remote execution
page can then show how long actions queued and ran, and list your runs with
their remote actions, outcome and timings, linking to each run's page under
Build Runs.
